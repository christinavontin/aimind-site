# Design files

Final files for aimind.marketing. All design rules live in Christina's private brand guide on claude.ai (see [`docs/design-guide.md`](../docs/design-guide.md)); the code in `src/` implements them; live site https://aimind.marketing/.

| Folder | Content |
| --- | --- |
| `logo/svg/`, `logo/png/` | Logo set: full logo and sign, navy, white and on white, 64 to 2400 px |
| `style-guide/` | Boards for logo, colors and typography (HTML) with PNG previews in `style-guide/previews/` |
| `screens/` | Screenshots of the current pages |
| `social/` | LinkedIn banners and company logo |
| `infographics/` | Infographics as images (2160 × 2700): HTML source per language, final PNG and `render.py` to rebuild a PNG from its source. On the website the same content is an HTML component in `src/components/`. |

Only final versions live here.
